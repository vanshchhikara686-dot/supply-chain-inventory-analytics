# Supply Chain & Inventory Optimization Analytics

An end-to-end supply chain analytics project using **SQL, Microsoft Excel, and Power BI**.

## Project Overview

This project analyzes supply chain and inventory data to support operational decision-making. The analysis and business findings will be documented here after reviewing the source dataset, SQL queries, and Power BI report.

## Tools

- SQL — data querying and analysis
- Microsoft Excel — data review and analysis
- Power BI — interactive dashboard and visualization

## Repository Structure

- `data/` — source dataset
- `sql/` — SQL analysis scripts
- `powerbi/` — Power BI report
- `screenshots/` — dashboard screenshots
- `documentation/` — supporting project documentation
